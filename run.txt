Project Title: DocMind | AI-Powered RAG Application Tech Stack: React, Vite, FastAPI, Python, ChromaDB, Groq API (LLaMA 3.1), Sentence-Transformers

Brief Bullet Points:

Built a full-stack RAG (Retrieval-Augmented Generation) application using React/Vite for the UI and FastAPI for a high-performance backend.
Implemented document parsing (PDF/DOCX) and semantic search using ChromaDB and local Sentence-Transformers for vector embeddings.
Integrated the Groq API (LLaMA 3.1) for blazing-fast, context-aware LLM query responses based on uploaded documents.
